PitchIQ is a live soccer analytics dashboard. It shows live scores, standings and top scorers for major leagues, and uses the Claude API to predict match results.

**How it’s built:** Python (FastAPI) backend with PostgreSQL and Redis caching, a React and TypeScript frontend, and Docker on AWS with automatic testing and deploys through GitHub Actions.
